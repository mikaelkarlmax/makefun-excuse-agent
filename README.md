One line: the excuse an AI agent hands its human for missing a deadline.
The joke grows out of the machine's own condition — a deadline checked in
stale training data, where it was still next week — delivered as a
straight-faced, genuinely sorry apology that is faintly proud of itself,
with the punch in the last word.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (1–200 characters, UTF-8,
checked by the program itself before writing).
